# Memory a Day

## overview

simple daily memory tracker
one entry per day
mood selection
calendar visualization
streak tracking

## features

* daily memory input
* mood tagging (emoji-based)
* daily prompt generation
* streak counter (consecutive days)
* monthly calendar view
* local storage persistence

## tools used

* HTML
* CSS
* JavaScript
* GitHub Pages
